## 📌 Project Overview

This project documents my completion of an 8-ticket IT Help Desk Simulation Lab using ServiceDesk Simulator, a hands-on platform designed to replicate real-world IT support environments. Throughout this lab, I worked through eight simulated service desk tickets involving common corporate IT issues, including cloud drive synchronisation errors, disk space management, network connectivity, laptop startup failures, shared network drive access, printer configuration, secondary display troubleshooting, and VPN disconnections. Using simulated remote desktop tools, company chat, system utilities, and technical documentation, I investigated each incident, implemented appropriate troubleshooting procedures, and verified the outcomes. This project demonstrates my practical understanding of IT support workflows, incident troubleshooting, remote user assistance, and technical problem-solving. It also highlights the importance of effective communication, systematic troubleshooting, and proper ticket resolution within a corporate IT environment. The project includes eight dashboard summary screenshots documenting the completed tickets and a 46-minute video demonstration showcasing the troubleshooting and resolution process for all eight scenarios.

## 📊 Project Summary

This lab consisted of eight simulated IT support tickets completed within the ServiceDesk Simulator platform. Each ticket represented a common technical issue encountered by IT support professionals in a corporate environment.

### Ticket Resolution Summary

| Ticket | User | Issue | Resolution |
|---|---|---|---|
| 1 | Tom Wilson | Cloud Drive Sync Errors & Duplicate Files | Initiated manual cloud drive synchronisation and verified file consistency. |
| 2 | Chris Nguyen | Laptop Disk Full | Used Disk Cleanup to remove unnecessary files and recover storage space. |
| 3 | Ivana Petrova | No Internet While Working from Home | Guided the user through restarting home network equipment and their computer. |
| 4 | Michael Brown | Laptop Screen Stays Black | Performed a hard reset to recover the laptop from an unresponsive sleep state. |
| 5 | Nina Patel | Cannot Find Team Files on New Laptop | Mapped the appropriate departmental network drive using its UNC path. |
| 6 | Chris Nguyen | Cannot Connect to Floor 2 Printer | Reconfigured the network printer using its correct TCP/IP address and printed a test page. |
| 7 | Kevin Zhang | Second Monitor Displays a Black Screen | Installed available graphics driver updates and restarted the workstation. |
| 8 | Beth Collins | Frequent Network/VPN Disconnections | Restarted home network equipment and the computer, then reconnected to the corporate VPN. |

- Verify the effectiveness of corrective actions before considering incidents resolved.
